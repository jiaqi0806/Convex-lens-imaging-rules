# 凸透镜成像规律实验模拟器

一个无需安装、可直接在浏览器打开的八年级科学互动实验网页。它模拟浙江教育出版社《科学》八年级上册“凸透镜成像规律”实验中的蜡烛、凸透镜、光屏、焦点和主光轴，并动态绘制三条特殊光线。

## 使用方法

1. 用浏览器直接打开 `index.html`。
2. 拖动实验区中的蜡烛，或调节“物距 u”和“焦距 f”滑动条。
3. 也可以直接输入物距、焦距数值；每个数值框两侧的 `−`、`＋` 按钮每次分别减少或增加 1 cm。
4. 观察焦点、光路、光屏位置、像距和成像特点的实时变化。
5. 使用“快捷观察”按钮快速切换五种典型成像情况。

该项目没有外部依赖，也不需要本地服务器；手机浏览器可直接打开。

## 发布为手机网址

这是纯静态网页，上传整个项目目录即可发布。推荐两种方式：

1. **Netlify Drop**：把项目压缩包上传到 Netlify Drop，平台会生成一个 `https://...netlify.app` 手机网址。
2. **GitHub Pages**：把文件上传到 GitHub 仓库，在仓库的 Pages 设置中选择从主分支发布。

如果需要由他人代为发布，需要提供可授权的 GitHub 仓库，或已登录的 Netlify/Vercel 托管账户；发布本身会创建公开的外部网址。

## 当前功能

- 光具座、蜡烛、凸透镜、光屏、主光轴、F 和 2F 的实验装置显示
- 拖动蜡烛和滑动条调节物距 `u`
- 滑动条调节焦距 `f`
- 直接输入物距、焦距，或用 `−`、`＋` 按钮逐次以 1 cm 调节
- 自动判断 `u > 2f`、`u = 2f`、`f < u < 2f`、`u = f`、`u < f` 五种情形
- 实时显示像距 `v`、正倒、大小和虚实
- 动态绘制平行光线、光心光线、焦点光线；虚像情形显示反向延长线
- 手机竖屏自适应布局

## 后续扩展建议

`app.js` 已将状态、光学计算、绘制和页面更新分开：

- 练习模式：调用 `getImageData(u, f)`，随机出题并比对学生答案。
- 实验记录：在 `render()` 后保存物距、焦距、像距及成像属性，导出 CSV。
- 新实验模块：复用现有“状态 → 计算 → SVG 绘制”的结构，增加平面镜、反射、欧姆定律或浮力页面。
